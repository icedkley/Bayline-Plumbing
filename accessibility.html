Accessibility

This page describes the accessibility features of the Bayline Plumbing demonstration site and what we've done to make it usable for everyone. This is a demonstration build, not a live business.

Our approach

This site was built to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at the AA level. That means semantic HTML, keyboard-navigable controls, visible focus states, sufficient color contrast, and screen-reader-friendly markup throughout.

What's in place

Every page uses semantic HTML — real <header>, <nav>, <main>, <footer>, and <section> elements with proper heading hierarchy. Interactive components like the mobile navigation and FAQ accordions are keyboard-accessible and manage focus correctly. Forms use real <label> elements, helpful error messages, and clear success states.

Keyboard navigation

Everything on this site can be reached and operated using only a keyboard. Press Tab to move through interactive elements, Enter or Space to activate buttons and links, and Escape to close the mobile navigation. Focus outlines are visible at all times.

Reduced motion

The site respects the prefers-reduced-motion system setting. If your device is set to reduce motion, animations and smooth scrolling are disabled.

Color contrast

All text on this site meets or exceeds the WCAG AA contrast ratio — 4.5:1 for body text and 3:1 for large text. Colors are never used as the only way to communicate information.

Images

Meaningful images include descriptive alt text. Decorative images use empty alt="" attributes so screen readers skip them.

Forms

Forms on this site use visible labels, appropriate input types, and inline error messages tied to their fields. Errors are announced to screen readers and don't rely on color alone.

Known limitations

This is a demonstration build. The contact form doesn't actually submit anywhere. If any part of the site isn't working the way it should for you, we'd like to hear about it — even on a demo.

Feedback

If you run into an accessibility problem on this site, reach out at hello@baylineplumbing.example and describe what happened. In a live version of the site, that would be a monitored inbox and we'd follow up.
